# pg-zhuagui

瀏覽器**抓烏龜**：先丟對子、再從別家盲抽，最後手裡剩下唯一一張烏龜牌的輸家出局。2–4 人（你＋1–3 AI）童玩桌遊，AI 三檔難度。**mobile-first**，桌面加寬。

也可當作 [Playgrounds（遊樂場）](https://play.samkuo.me/) 的 **SAM**（`index.html` 入口）。

## 一鍵開 SAM 小

```
https://play.samkuo.me/?open=sampot/pg-zhuagui&name=抓烏龜&fresh=1
```

同源會重用本機已匯入的沙盒；要強制新建可加 `&fresh=1`。

## 試玩（本機）

```bash
npx --yes serve .
# 或
python3 -m http.server 8080
```

點一下頁面後音效才會出聲。

## 操作

| 操作 | 說明 |
| --- | --- |
| **安裝面板** | 開局前選 **人數（2–4）** 與 **AI 難度**（輕鬆/標準/艱困），按「開始發牌」 |
| **點對手的牌背** | 從該家盲抽一張（隨機一張） |
| **來下一局** | 本局結束後，結算分數並繼續（沿用人數與難度） |
| **變更設定** | 結算面板回安裝面板，分數與戰績保留 |
| **重開這局** | 進行中重發一輪，本局分數不計 |
| **對局紀錄** | 展開查看每一次抽牌與配對結果 |
| **👁 追蹤** | 開／關各家牌背下「曾被抽走」小徽章 |
| **音效開／關** | 靜音（會記住，下次開遊還是一樣） |

抽到能湊對的牌會立刻丟掉一對；手牌只剩下烏龜牌的人出局，其餘各家 +1 分。

## 規則

- 52 張撲克＋1 張烏龜牌（鬼牌），依人數（2–4）盡量平分。
- 開局各家先丟「對子」（同數字、不限花色）。
- 輪到你時選一位對手盲抽；若能配對就丟出一對。
- 最後剩下唯一一張牌（烏龜牌）的持有者為輸家；其餘各家 +1 分。
- AI 難度：輕鬆＝隨機抽；標準＝抽牌最多的家；艱困＝愛抽你、避開只剩一張的家。
- 抽牌結果以揭示卡演出：牌翻面飛入，成對時雙卡並列丟出。

## 生涯戰績

- **連勝**：連續沒當烏龜的局數，自己拿到烏龜就歸零。
- **生涯**：總場次、當烏龜次數、對各 AI 的對戰成績、最佳連勝與音效偏好，存在單一 JSON key `GET/PUT /api/kv/pg-zhuagui-stats`；舊版 `pg-zhuagui-best`（純數字）會在啟動時一次性遷移。沒有 KV 環境（純本機 serve）時也照玩，只是不跨場保存。
